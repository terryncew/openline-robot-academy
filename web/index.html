    Educator Guide & 45-Minute Workshop Plan
    
  
    Students predict, program, observe, and revise. Success means explaining a choice, not finishing fastest. 
    
  
      
    
    1. 0–5 min · First delivery (Sequences & State). Point right together, then open Mission 01. Ask students to tap Forward three times and press Run. Check: can they explain why Turn left changes facing without changing tiles?
      2. 
    
    2. 5–15 min · Garden path (Counted Loops). Build Mission 02: Repeat 4 { Forward }, tap "After End ⤵", Turn left, Repeat 3 { Forward }. Ask: what happens if Turn left is put inside the first Repeat group?
      3. 
    
    3. 15–27 min · Sensor scout (Conditionals & Feedback). Build Until pad → If clear → Forward → Else → Turn left. Test the exact same program on routes A, B, and C. Discuss why re-checking the sensor generalizes across lengths, and what maze shape would break a left-turn-only rule.
      4. 
    
    4. 27–37 min · Safety lab (Debugging, Fail-Closed & E-Stop). Step through the buggy starter, remove Block 01 (Turn left), and complete all 4 safety drills: Normal delivery, Crate appears, Sensor fails ("unknown"), and mid-run Emergency stop + explicit Reset.
      5. 
    
    5. 37–45 min · Creative sandbox & Code lab (Synthesis). Pairs design a custom maze in Mission 05 (Creative sandbox) and trade devices to solve each other's challenge, or edit Robot JavaScript and compare Python in Code lab.
      6. 
  
    
  
    Answer Key & Misconception Coaching
    
  
      
    
    • 01 First delivery: move(); move(); move(); · Reflection answer: Right one tile, then up one tile.
      • 
    
    • 02 Garden path: repeat(4) { move(); } left(); repeat(3) { move(); } · Reflection answer: A small square, ending where it started.
      • 
    
    • 03 Sensor scout: while (!atGoal()) { if (clearAhead()) { move(); } else { left(); } } · Reflection answer: It checks the path again before each move.
      • 
    
    • 04 Safety lab: Remove initial left(); leaving repeat(5) { move(); } · Reflection answer: Stop and check before moving again.
      • 
    
    • 05 Creative sandbox (default Zigzag): repeat(2) { move(); move(); left(); move(); right(); } · Reflection answer: Write and run a working solution on the map yourself first.
      • 
  
    
  
    Shared Devices, Accessibility & Troubleshooting
    
  
    Pair protocol (2–3 students per device): Driver operates buttons; Navigator predicts each step and watches Step detective; optional Safety Observer calls Emergency stop on hazards. Swap roles every mission (or every 5 minutes).
    
  
    Troubleshooting: If blocks are added inside a loop by mistake, tap Undo or tap the After End ⤵ button on the End row. If controls are locked in red, Emergency stop is latched—press Reset to release. If a browser blocks local HTML files, serve web/ from a local server or approved HTTPS host, or use the unplugged paper grid backup.
    
  
    This guide is structured for a 45-minute workshop; real classroom validation with students and educators remains pending.
